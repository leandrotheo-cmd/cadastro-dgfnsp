Abrir o sistema
iPhone / iPad (use o Safari):
  1. Toque no botão Compartilhar (quadrado com seta ↑).
  2. Escolha Adicionar à Tela de Início.
  3. Toque em Adicionar.
Instalação manual:
  1. Android (Chrome): menu ⋮ → Instalar app ou Adicionar à tela inicial.
  2. Windows (Edge): menu … → Aplicativos → Instalar este site como aplicativo.
  3. Windows (Chrome): menu ⋮ → Transmitir, salvar e compartilhar → Instalar página como app.
Aplicativo instalado. Procure o ícone DGFNSP na tela inicial ou no menu Iniciar.
O acesso é feito com o usuário e a senha fornecidos pelo administrador.
